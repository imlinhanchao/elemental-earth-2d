# 《元素纪元 2D》（Elemental Earth 2D）项目设计与工程库

《元素纪元 2D》（Elemental Earth 2D）是由网页版放置游戏《元素纪元》全面升维而来的 **2D 六边形沙盒工业模拟 + 真实化学反应与元素发现游戏**。

---

## 🌟 重大实装里程碑（本次新增）

根据需求与系统设计规范，现已全面实装五大支柱核心体系：

### 1. 柏林噪声程序化六边形大世界（Procedural Hex-World）
- 采用 **FastNoiseLite 柏林/单峰噪声算法**，基于尖顶六边形拓扑算法实时演算大地；
- 包含 **4 大生态群落**（平原草地、赤红火山带、高盐盐湖、原始森林）；
- 矿脉与资源根据群落地质合理分布：孔雀石矿床、赤铁矿脉、硫磺矿、石盐（NaCl）与林木。

### 2. 微观实验工作台与动态化学动画（Cleanroom Workbench & Reactions）
- 按 **`L`** 随时进入微观实验台视口：
- 支持自由添加原料、控制酒精灯火焰升温；
- **真实唯象化学动画**：溶液根据生成物实时变色（孔雀石翠绿、纯铜紫红沉淀、铁红、纯水色）、沸腾气泡粒子动态翻滚与烟雾升腾；
- **工艺固化导出**：小试成功后，点击“工艺固化”导出**【工业工艺蓝图芯片（Process Blueprint）】**！

### 3. 工艺解锁与工业反应塔批量量产（Mass Production & Industrial Reactor）
- 按 **`R`** 可在野外建造大型**工业连续反应塔**；
- 插入导出的蓝图芯片（如：密闭干馏木炭、工业熔炼铜、高炉炼铁），反应塔只要原料充足，即开启**全自动无人化流水线生产**，大批量自动入库！

### 4. 工具制造工坊与采矿威力跃升（Tool Crafting System）
- 按 **`T`** 打开冶金锻造砧：
  - 消耗金属铜打造 **【纯铜地质镐】**（开采伤害 2，采矿速度 +100%）；
  - 消耗金属铁打造 **【精钢地质重锤】**（开采伤害 4，采矿速度 +300%，一击粉碎矿脉）；
- 采矿具备真实的受击挤压、矿石晃动与碎裂反馈。

### 5. 时代演进与文明跨越庆典（Era Progression System）
- 游戏严格遵循真实科学史的 6 大时代演进（石器时代 $\rightarrow$ 炼金术时代 $\rightarrow$ 近代化学 $\rightarrow$ 电化学 $\rightarrow$ 稀土时代 $\rightarrow$ 原子能时代）；
- 当达成时代突破里程碑（如首次炼出单质铜、导出工业蓝图）时，触发全屏**【文明纪元跨越】震撼庆典**！

## 🕹️ 键盘操作指南（纯键盘优先，手柄即插即用）

| 功能 | 键盘按键 | 说明 |
| :--- | :--- | :--- |
| **角色移动** | **`W / A / S / D`** 或 **方向键** | 8向平滑移动，自动识别朝向 |
| **开采 / 采矿** | **`Space (空格)`** 或 **`J`** | 面向矿脉/树木敲击开采（受工具威力加成） |
| **微观化学实验台** | **`L`** | 自由拼装试剂、点燃酒精灯、导出工业蓝图芯片 |
| **工具锻造工坊** | **`T`** | 锻造纯铜镐与精钢重锤，升级采掘能力 |
| **118 周期表墙** | **`P`** | 查看全屏元素周期表圣殿，已提纯单质金光闪耀 |
| **建造陶土熔炉** | **`C`** 或 **`B`** | 消耗 4 块木材就地建造 |
| **建造工业反应塔** | **`R`** | 消耗 6 块木材建造全自动连续流工业反应器 |
| **熔炉快捷生火** | **`1`** (靠近熔炉时) | 投入木炭升温生火 |
| **熔炉快捷炼铜** | **`2`** (靠近熔炉时) | 投入孔雀石炼铜 |
| **熔炉快捷炼铁** | **`3`** (靠近熔炉时) | 投入赤铁矿炼铁 |
| **退出 / 关闭面板** | **`ESC`** | 关闭当前打开的所有窗口 |
