## 💡 核心设计精要速览

1. **三大支柱解耦（Decoupled Three Pillars）**：
   - **🪨 开采资源（Extraction）**：地质找矿、定向爆破、三态原生物流与危险环境防护。
   - **⚙️ 生产制造（Manufacturing）**：全面做“轻量化与标准化”，杜绝繁琐齿轮组装；机器由物理化学工况（耐温/耐腐蚀/承压）定义。
   - **⚗️ 实验反应（Laboratory）**：微观组装仪器，自由试错，攻关提纯纯净单质并点亮 118 周期表，导出【工业工艺蓝图】。
2. **小试到量产闭环（Lab Scale-up to Factory）**：
   - 实验室负责**“从 0 到 1”**的科学发现；
   - 工业区负责**“从 1 到 100”**的大型连续流反应塔量产。
3. **唯象化学求解器（Universal Reaction Solver）**：
   - 彻底摒弃穷尽不能的硬编码配方表；
   - 由**复分解离子池、氧化还原电势差、高温热解、电解定向放电、相变溶解平衡** 5 大客观定律全自动结算全天下化学反应！
4. **单机与 1~4 人联机合作（Co-op）**：
   - 房主权威同步架构（Steam P2P Relay），科技与元素全队共享，背包与实验操作各自独立。
