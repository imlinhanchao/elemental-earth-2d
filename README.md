# 《元素纪元 2D》（Elemental Earth 2D）项目设计与工程库

《元素纪元 2D》（Elemental Earth 2D）是由网页版放置游戏《元素纪元》全面升维而来的 **2D 顶视角单机/联机（1~4人）沙盒模拟游戏**。

---

## 🎮 M1 原型现已初步可玩！

我们已经成功基于 **Godot Engine 4.2** 构建了首个**“野外探索 ➔ 开采矿脉 ➔ 实体熔炉煅烧 ➔ 提纯单质铜 ➔ 点亮元素周期表”**的端到端完整闭环！

### 快速启动体验（macOS）

在终端中进入本项目目录并直接运行启动脚本即可调出游戏窗口：

```bash
cd /Users/hancel/Documents/project/elemental-earth-2d
./run_game.sh
```

或者：在你的 `/Applications/Godot.app` 中导入此目录工程，按 `F5` 直接运行！

### 🕹️ 游戏操作指南

| 按键 / 操作 | 功能描述 |
| :--- | :--- |
| **`W / A / S / D`** 或 **方向键** | 控制角色在 2D 大世界中平滑移动探索 |
| **鼠标左键点击【矿脉/树木】** | 靠近后敲击开采孔雀石、赤铁矿与木材，掉落后直接进入背包 |
| **靠近【陶土熔炉】** | 右侧自动升起熔炉控制面板，可投入原料与木炭生火 |
| **点击【+ 投入孔雀石】与【+ 加木炭生火】** | 炉温升至 800K 以上时，自动激发唯象化学反应，炼出金属铜！ |
| **提纯成功成就反馈** | 自动收获金属铜，并在左侧点亮 **第 29 号元素：铜 (Cu)** 徽章！ |
