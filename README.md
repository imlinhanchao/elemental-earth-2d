# 《元素纪元 2D》（Elemental Earth 2D）项目设计与工程库

《元素纪元 2D》（Elemental Earth 2D）是由网页版放置游戏《元素纪元》全面升维而来的 **2D 顶视角单机/联机（1~4人）沙盒模拟游戏**。

---

## 🎮 现已全面实装【纯键盘优先 & 手柄原生兼容】操作体系！

我们彻底革新了操作手感：**双手无需触摸鼠标**，走过去面向物体直接按键交互，探索、采矿、投料与建造流畅盲操！

### 快速启动体验（macOS）

在终端中进入本项目目录并直接运行启动脚本即可调出游戏窗口：

```bash
cd /Users/hancel/Documents/project/elemental-earth-2d
./run_game.sh
```

或者：在你的 `/Applications/Godot.app` 中导入此目录工程，按 `F5` 直接运行！

### 🕹️ 键盘与手柄键位映射表（Keyboard & Gamepad Map）

| 操作功能 | 键盘键位 (Keyboard) | 手柄对应 (Xbox / PS / Deck) |
| :--- | :--- | :--- |
| **移动走动** | **`W / A / S / D`** 或 **方向键** | **左摇杆** 或 **十字键 (D-Pad)** |
| **开采 / 采掘动作** | **`Space (空格)`** 或 **`J`** | **`A` 键** (Xbox/Deck) / **`×`** (PS) |
| **建筑交互 / 打开面板** | **`E`** | **`X` 键** (Xbox/Deck) / **`□`** (PS) |
| **熔炉快捷生火** | **`1`** | 方向键上 / 快捷轮盘 |
| **投入孔雀石 (炼铜 Cu)** | **`2`** | 方向键左 / 快捷轮盘 |
| **投入赤铁矿 (炼铁 Fe)** | **`3`** | 方向键右 / 快捷轮盘 |
| **现场建造新熔炉** | **`C`** 或 **`B`** | **`Y` 键** (Xbox/Deck) / **`△`** (PS) |
| **打开 118 周期表墙** | **`P`** | **`View / Select` 键** |
| **关闭弹窗** | **`ESC`** 或 **`P`** | **`B` 键** (Xbox/Deck) / **`○`** (PS) |
